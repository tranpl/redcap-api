# REDCap API Library for .NET

## What's New in 2.0.x

The .NET 11 library supports the public REDCap 17.5.10 API reference and bulk ODM record import. The repository includes a credential-free demo and a stdio MCP server with 55 tools. See the [project README](../../../README.md) for current capabilities, installation, credential configuration, build numbering and offline verification.
